MonstersRun
===========

A simple terminal runner game written in Python. Dodge obstacles and monsters as you run!

## How to Play

```bash
python game.py
```

- **SPACE** – Jump over obstacles (`#`) and monsters (`M`)
- **Q** – Quit

## Rules

- The game speeds up as your score increases (levels up every 100 points)
- Hitting an obstacle or monster ends the run
- Try to beat your high score!
